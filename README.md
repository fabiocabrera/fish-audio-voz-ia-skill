# Voz de IA humana nos seus Reels com Fish Audio / Human-sounding AI voice for your Reels with Fish Audio

## Português

Esta skill ajuda quem produz Reels, vídeos curtos ou qualquer conteúdo narrado a trocar uma voz de IA com cara de robô por uma voz humana, usando a API de texto para voz do Fish Audio. Serve para criadores, social media e desenvolvedores que já têm (ou querem montar) uma rotina de vídeo e precisam de narração em português do Brasil.

Ela cobre a arquitetura da integração, a chamada da API, como escolher e aprovar vozes, como encaixar o áudio num pipeline de vídeo (velocidade, legenda sincronizada, fallback), cuidados de segurança e de conformidade, e prompts prontos para pedir ao Claude que construa tudo. Não contém credenciais nem dados de uma operação real.

### Instalação em 3 passos

1. Baixe o repositório (`git clone`) e copie a pasta `skills/fish-audio-voz-ia` para `~/.claude/skills/` (Windows: `C:\Users\SEU_USUARIO\.claude\skills\`). Para usar só em um projeto, copie para `.claude/skills/` dentro dele.
2. Reinicie a sessão ou recarregue as skills do ambiente.
3. Peça ao Claude para usar `fish-audio-voz-ia` ao planejar ou construir a narração por IA dos seus vídeos.

## English

This skill helps creators, social media teams and developers who make Reels, short videos or any narrated content replace a robotic-sounding AI voice with a human-sounding one, using the Fish Audio text-to-speech API. It targets people who already run (or want to build) a video routine and need Brazilian Portuguese narration.

It covers the integration architecture, the API call, how to choose and approve voices, how to fit the audio into a video pipeline (speed, synced captions, fallback), security and compliance care, and ready-made prompts to ask Claude to build it all. It contains no credentials or real operational data.

### Installation in 3 steps

1. Download the repository (`git clone`) and copy the `skills/fish-audio-voz-ia` folder into `~/.claude/skills/` (Windows: `C:\Users\YOUR_USER\.claude\skills\`). To use it in a single project, copy it to `.claude/skills/` inside that project.
2. Restart the session or reload the environment's skills.
3. Ask Claude to use `fish-audio-voz-ia` when planning or building AI narration for your videos.
